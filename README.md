# Проект E-commerce Core

## Описание

Этот проект представляет собой ядро для интернет-магазина, реализованное с применением объектно-ориентированного программирования (ООП). Основные сущности проекта — классы **Product** (товары) и **Category** (категории товаров), а также наследники товаров: **Smartphone** (смартфон) и **LawnGrass** (трава газонная).

В проекте реализованы базовые функции работы с товарами и категориями: хранение атрибутов, подсчёт количества продуктов, строковое представление, обработка сложения товаров с ограничением на комбинации классов и защита добавления объектов в категории.

Проект подготовлен к расширению и интеграции с внешними интерфейсами (веб-приложения, телеграм-боты и др.).

***

## Функциональность, реализованная в проекте

Реализован абстрактный базовый класс BaseProduct, описывающий общую функциональность для товаров.

Добавлен класс-миксин PrintInfoMixin, который при создании объекта печатает в консоль информацию о классе и его параметрах.

Класс Product наследует и базовый класс, и миксин, что позволяет расширить функционал и вести логирование создания объектов.

Обеспечено тестирование новой функциональности с покрытием более 75%.

## Технологии и инструменты

- Python 3.13+
- Работа с виртуальными окружениями (Poetry)
- Чистый код по стандарту PEP 8 (flake8)
- Форматирование кода (black, isort)
- Статический анализ и проверка типов (mypy)
- Модульное тестирование (pytest, pytest-cov)

## Запуск и тестирование

- Установка зависимостей и создание виртуального окружения:

```bash
poetry install
poetry shell
```

- Запуск тестов с отчётом покрытия:

```bash
pytest --cov=src --cov-report=term --cov-report=html
```

- Открыть `htmlcov/index.html` для просмотра отчёта по покрытию.
